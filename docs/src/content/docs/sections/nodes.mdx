## Nodes

Excel sheet `Nodes` · HTML `nodes.html` · JSON `nodes.json` · always generated; nodes filtered by
`Node.Names` (see [Settings](/cv4pve-report/settings/)).

One row per node, sorted by name. For every node that is online and known, the report calls
`/nodes/{node}/status`, `/version`, `/subscription`, `/dns`, `/time` and `/network` in parallel.
Offline or unknown nodes get a row with only the cluster-resource fields filled in.
The interface list fetched here also feeds the Network section and the network diagram.

The table has no title, so `nodes.json` is a plain array of rows. The **Node** column links to the
node's detail page.

| Excel / HTML | JSON | Content |
|---|---|---|
| Node | `node` | Node name. Links to the node detail page. |
| Status | `status` | Node status from `/cluster/resources`. |
| Health | `healthScore` | Health score 0-100, higher is healthier (see the note below). |
| Uptime | `uptime` | Uptime as formatted text. |
| Cpu Size | `cpuSize` | Number of CPUs from `/cluster/resources`. |
| Cpu Cpus | `cpuCpus` | Logical CPUs (`cpuinfo.cpus`). |
| Cpu Sockets | `cpuSockets` | CPU sockets. |
| Cpu Cores | `cpuCores` | Cores per socket. |
| Cpu Model | `cpuModel` | CPU model string. |
| Cpu Mhz | `cpuMhz` | CPU clock in MHz, as returned by the API. |
| Cpu Hvm | `cpuHvm` | Hardware virtualization support flag, as returned by the API. |
| Memory Size GB | `memorySize` | Total memory. |
| Memory Usage GB | `memoryUsageBytes` | Used memory. |
| Memory Usage % | `memoryUsage` | Memory used / total. |
| Swap Total GB | `swapTotal` | Swap size (0 when node status is not available). |
| Swap Used GB | `swapUsed` | Swap in use. |
| Swap Usage % | `swapUsage` | Swap used / total; empty when there is no swap. |
| Disk Size GB | `diskSize` | Root disk size from `/cluster/resources`. |
| Disk Usage GB | `diskUsageBytes` | Root disk used. |
| Disk Usage % | `diskUsage` | Root disk used / size. |
| Root Fs Total GB | `rootFsTotal` | Root filesystem size from node status (0 when not available). |
| Root Fs Used GB | `rootFsUsed` | Root filesystem used. |
| Root Fs Usage % | `rootFsUsage` | Root filesystem used / total; empty when total is 0. |
| Kernel Version | `kernelVersion` | Full kernel version string (`kversion`). |
| Kernel Release | `kernelRelease` | Running kernel release. |
| Boot Mode | `bootMode` | Boot mode (EFI or legacy BIOS). |
| Secureboot | `secureboot` | Flag: Secure Boot enabled. |
| Cgroup Mode | `cgroupMode` | cgroup mode reported by the cluster. |
| Pve Version | `pveVersion` | `pve-manager` version string. |
| Version Version | `versionVersion` | Version from `/nodes/{node}/version`. |
| Version Release | `versionRelease` | Release from `/nodes/{node}/version`. |
| Subscription | `subscription` | Subscription level: `None`, `Community`, `Basic`, `Standard` or `Premium`. |
| Subscription Product Name | `subscriptionProductName` | Subscription product name. |
| Subscription Reg Date | `subscriptionRegDate` | Subscription registration date, as text. |
| Time | `time` | Node time zone. |
| Dns Search | `dnsSearch` | DNS search domain. |
| Dns1 | `dns1` | First DNS server. |
| Dns2 | `dns2` | Second DNS server. |
| Dns3 | `dns3` | Third DNS server. |

:::note[Health score]
The score comes from the Corsinvest API library: 100 − (CPU% × 0.4 + RAM% × 0.4 + Disk% × 0.2),
clamped to 0-100 and rounded to one decimal. The HTML report colours it green from 80, yellow from
60 and red below; Excel uses a red-yellow-green colour scale with 60 as the midpoint.
:::

## Node detail

Excel sheet `Node <name>` · HTML `nodes/<name>.html` · JSON `nodes/<name>.json` · enabled by
`Node.Detail.Enabled` (see [Settings](/cv4pve-report/settings/)).

One page per node, created only for nodes that are online and known. In HTML and JSON the node name
is lower-cased and dots, colons, spaces and underscores become `-`; the Excel sheet name is cut to
31 characters. A name that collides with an existing one gets a `_2`, `_3`, … suffix. The Excel sheet
and the HTML page have a back link to **Nodes**.

In `nodes/<name>.json` the header block is under `info` and each table below is under the JSON key
shown next to its title. Tables are written even when they are empty.

### S.M.A.R.T. Data (JSON `smartData`)

`Node.Detail.Disk.IncludeSmartData` is on (off by default). The report makes one
`/nodes/{node}/disks/smart` call per disk, up to `MaxParallelRequests` at a time. When a call fails,
the disk gets one row with Id `0`, Name `Error`, Value `-1` and the error message in Raw.

| Excel / HTML | JSON | Content |
|---|---|---|
| Disk | `disk` | Device path. |
| Model | `model` | Disk model. |
| Disk Type | `diskType` | Disk type. |
| Disk Health | `diskHealth` | Health from the disk list. |
| Smart Health | `smartHealth` | Health from the SMART call. |
| Id | `id` | Attribute ID. |
| Name | `name` | Attribute name. |
| Value | `value` | Normalized value. |
| Worst | `worst` | Worst normalized value. |
| Threshold | `threshold` | Failure threshold. |
| Flags | `flags` | Attribute flags. |
| Raw | `raw` | Raw value. |
| Fail | `fail` | Failure indicator. |

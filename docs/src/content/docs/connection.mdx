cv4pve-report talks to the Proxmox VE REST API of any node of the cluster. Create the user and API token
first — see [Permissions](/cv4pve-report/permissions/).

## Options in a file

A monthly report run by cron or Task Scheduler repeats the same connection every time: keep it in a file.

<CliResponseFiles
  tool="cv4pve-report"
  user="report@pve"
  token="report"
  extra={['# Your own selection of sections, see Settings', '# --settings-file=/etc/cv4pve/report-settings.json']}
  run="export --format Html -o /srv/reports/cluster"
/>

`--settings-file` goes before `export`, so it can live in the same file as the connection.
